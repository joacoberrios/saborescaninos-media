# Sabores Caninos — Tienda web + media de Instagram

- `index.html`, `assets/`, `datos/productos.json`: tienda online (GitHub Pages). Catálogo → carrito → pedido por WhatsApp.
- `assets/config.js`: **datos del negocio** (WhatsApp, zonas, costos de envío, envío gratis, horarios, medios de pago).
- `datos/productos.json`: se genera con `herramientas/catalogo.py` del repo `marketing-SABORESCANINOS` (precios de PlusPet, ofertas en bolsas grandes).
- `media/`: imágenes públicas que usa la API de Instagram para publicar (solo piezas aprobadas).

Publicar la web: Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
